# 对比学习

只在用户明确要求对比学习或调用本 skill 时启用。依赖同级安装的 [de-slop-it 总入口](../de-slop-it/SKILL.md)，先读总入口及本次相关的语言、文体规则。

## 比较版本

用户已标明人为修改版本时，以其说明为准。未标明时可以依据改动特征指出更可能的修改稿，并说明这是文本比较的推测；仅凭文风不能确认作者身份，不输出伪精确概率。只有一篇且无可用原稿时，先请用户提供另一版本或标注修改，不能虚构差异。

按对应段落识别实质改动，区分事实修正、结构调整和措辞变化。关注主语与动作、信息重心、句间逻辑、语序、句长节奏、缩写、修辞、标点、情感与视角。对比必要的原句与改句可以出现在本次回答中，不等于加入语料库。

从真实差异提炼方法，并注明适用语言、文体和条件。不要把改稿的笔误、事实丢失或无依据的断言总结成写作优点，也不要仅凭单次词语替换制定永久禁词。

## 输出与写回

默认输出版本判断（注明用户标注或推测）、关键修改比较、方法论总结。用户明确要求更新或记住方法时，按 [维护说明](../de-slop-it/references/maintenance.md) 写回方法论文件。

即使允许更新方法论，也不增加例子库。只有用户特别要求收录例子时，再使用 [例子维护](../de-slop-it-examples/SKILL.md)。用户仅要求总结时不修改安装文件。
